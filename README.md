# Quick Start Living Particles v6

- Default dark background; toggle to white in the live app.
- Individually simulated particles in several wandering local vortices.
- Pointer/touch interaction: repulsion and a tangential wake while dragging.
- Adjustable particle color, density, speed, vortex strength and touch response.
- Static-host friendly: GitHub Pages, no dependencies.

Upload the three files to the repository root and enable GitHub Pages.
